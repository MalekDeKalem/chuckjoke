CLI tool to get Chuck Norris jokes from the [Chuck Norris Jokes API](https://api.chucknorris.io/).

## Example usage
```Bash
./chuckjoke -l                # lists all the available categories
./chuckjoke -c "animals"      # gives a random joke from the given category
./chuckjoke -c "animal,music" # gives a random joke from either of the two categories
./chuckjoke                   # gives a random joke from any category
```
